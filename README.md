# 寵物陪伴刊登平台

一個媒合「想和寵物相處的消費者」與「帶著寵物提供陪伴服務的訓練師」的網站。
訓練師刊登自己的寵物與可預約時段，消費者瀏覽後線上預約、付款，結束後互相評價；
管理員負責審核刊登與訓練師資格、確認收款、處理退款與申訴，並查看平台營運統計。

> 本專案為學生專題，**付款流程為模擬**，不會連接任何真實金流。

## 主要功能

### 消費者
- 瀏覽與搜尋刊登（依關鍵字、狗／貓分類），首頁顯示評價最高的刊登
- 依訓練師開放的星期與時段預約，選擇見面地點（到府、指定店家、公共區域）
- 模擬信用卡付款，可儲存卡片下次直接使用
- 訂單分為待確認、即將到來、歷史紀錄，可依日期篩選
- 取消訂單（需在刊登規定的時限前，每月最多 2 次；已付款會建立退款任務）
- 申請改期（每筆訂單最多 2 次，需訓練師同意；時數變少會自動退差額）
- 與訓練師即時聊天、完成後評價訓練師、對訂單提出申訴
- 管理個人資料、大頭貼與退款用銀行帳戶，並可申請成為訓練師

### 訓練師
- 新增、編輯刊登（上傳多張寵物照片、設定價格、時段、取消時限），送出後需管理員審核
- 下架、重新上架、刪除刊登
- 接受或拒絕訂單（時段重疊時會跳出提醒），開始與完成行程
- 行事曆檢視已接受與進行中的訂單
- 平台帳戶：查看每筆收入與抽成、餘額變化，申請提領
- 等級制度：依消費者平均評分升為「進階」或「專業」，平台抽成隨之降低
- 查看收到的評價、評價消費者、封鎖消費者（黑名單）

### 管理員
- 審核新刊登與刊登修改、審核訓練師申請
- 訂單追蹤與確認收款（確認後款項才會計入平台帳戶，訓練師才能開始行程）
- 退款與補款管理、處理申訴案件並回覆
- 會員管理（查詢、編輯、刪除）
- 審核訓練師的提領申請
- 統計儀表板：交易總額、平台淨收入、完成率、申訴率、回購率、熱門時段、訓練師排行
- 平台設定：各等級抽成比例與升級門檻

## 訂單流程

```
消費者預約 ─▶ 待確認 ─(訓練師接受)─▶ 已確認 ─(消費者付款、管理員確認收款)─▶ 可開始
                │                        │
         訓練師拒絕 ▶ 已拒絕         消費者取消 ▶ 已取消（已付款則建立退款任務）

可開始 ─(訓練師開始)─▶ 進行中 ─(訓練師完成)─▶ 已完成 ─▶ 款項扣除抽成後撥入訓練師帳戶，雙方可互評
```

狀態只能依上圖的順序前進，例如未付款或未確認收款的訂單無法開始，未開始的訂單無法完成。

## 技術

- 後端：Python 3、Flask 3（Blueprint 分層）、原生 sqlite3
- 前端：Jinja2 模板、原生 HTML／CSS／JavaScript
- 資料庫：SQLite（`database.db`），完整結構在 `schema.sql`

## 啟動網站

```bash
pip install -r requirements.txt
python app.py
```

接著用瀏覽器開啟 http://127.0.0.1:8000 。

如果要從空白開始建立一個新的資料庫（不會刪除既有資料，只會補上缺少的資料表）：

```bash
flask --app app init-db
```
